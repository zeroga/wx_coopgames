# AW UI 修订 · 2026-10-04

本轮继续 PR #8，基于 `cf32fa3`，沿用 `2026.10.04.6`。仅提交代码和本地检查结果，不上传微信体验版；未访问或写入真实玩家档、车队档或数据库。

## 七项反馈与改动

| 反馈 | 实现 |
| --- | --- |
| 前置 / Token 配置页面对齐混乱 | 取消作为紧凑右侧操作；标题占剩余空间，所有已知路线、忽略和自定义选项统一宽度及左右边距。 |
| 各处车辆展示风格及标识不一致 | 新增 `aw-vehicle-label`，统一为类型图标和简称、等级标志、车名。所有独立车辆条目及过渡目标共用组件；信息、状态和操作按所在页面组织。 |
| 黄色感叹号太大 | 可见直径 18px，透明按钮保持 44×44px 点击区域；相邻操作使用独立区域，不通过负边距覆盖邻居。 |
| 车队车辆与操作比例失衡 | 车名用 32rpx 粗体；编辑 / 移除改为 24rpx 文字次级操作，移除保留红色。名称和元信息分行组织，操作不再铺满条目宽度。 |
| 职责管理行和按钮太大 | 名称、拖动柄、上下移和编辑 / 删除优先同一行；空间不足时操作整体换至第二行，保持紧凑文字和独立点击区域。第一项不能上移，最后一项不能下移。 |
| “待确认”核验备注仍出现 | 能力状态、弹药获取状态、性能统计口径、配件分组和说明均经过显示层处理；后台原始字段、来源及核验状态完整保留。 |
| “资料分组 2”没有用户含义 | 这是按照 `configuration_key` 遍历生成的内部显示序号，不是武器数量或配件等级。移除序号，武器名称、参数和弹药仍完整显示。 |

## 车辆标识与更新

车型图标采用工具内几何标识，同时附上车型简称，避免仅凭形状猜测类型：MBT `◈`、LT `◇`、TD `▲`、AFV `●`、SPG `■`。图标不依赖远端图片。等级优先显示 `Tn`，传奇车显示“传奇”；资料缺失显示 `T—` 和车型占位，不猜测填充。

车名、车型和等级来自当前安装的目录。页面刷新传入目录 revision，组件重新读取同一 ID 的最新资料；前置 / 编辑弹层继续沿用资料更新期间的既有冻结机制。详情标题使用同一组件的标题尺寸，其他车辆保持相同字体与标识。

显示层隐藏核验标签和纯核验备注，不改后台 `availability`、`verification_status`、`configuration_key` 或原始说明；默认、研发、升级及是否具备等实际状态保留。未知奖励 / 路线继续不能凭空参与计算。玩家的奖励进度、未满足条件和需要前置提示仍保留，它们是个人规划状态，不是资料核验标签。
