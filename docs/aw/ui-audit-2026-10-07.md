# 车辆编辑弹层 UI 审查（2026-10-07）

审查基线：用户已确认的 [UI 规范 v2.2](../design/ui-design-system.md)与[配套样板](../design/ui-design-system-sample.html)；被审实现为 PR #8 / `7d16943` / `2026.10.07.2`。

用户已在 iPhone 确认操作恢复正常，但截图中正文右侧越界：车辆状态、职责等级、职责管理入口和备注框不能完整显示。按规范 §17.1，先核对规则及样板，再修实现。

## 验证与边界

使用仓库真实 WXML、WXSS、车辆身份模板和合成编辑数据做浏览器布局检查，并模拟原生 scroll-view 默认 `width:100%`。浏览器只用于检查尺寸/边界与点击覆盖，不模拟微信触摸、键盘或实际安全区。

- 在 390px 场景复现旧问题：标题和按钮栏横向边界约 `12.47–377.53px`；旧正文为 `12.47–402.47px`，右边越界。修正后正文为 `12.47–377.53px`。
- 24 个修改后场景通过：320 / 375 / 390 / 768px × 普通表单 / 长职责及过渡目标 / 职责管理 × 键盘收起 / 模拟300px键盘。正文与标题左右边界一致，控件不横向越界，正文不覆盖底部操作，按钮中心命中正确。
- 新增宽度回归覆盖手机、平板及窄弹层容器；继续检查原生测量过期回调、键盘恢复、背景滚动锁定、固定 textarea 和原生模板编译。

iPhone 复测仍需重新编译或使用新的预览/体验版本：截图中的计划、三种职责等级、职责管理入口、备注框应完整落在标题卡/操作栏的横向范围内。检查左右内边距、正文滚动、键盘展开/收起、职责管理返回及保存/取消，确认前一版已恢复的操作继续可用。
