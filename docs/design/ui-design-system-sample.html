8. 本次整合中主动删除 / 合并的项目

避免重复标准和历史草案继续干扰实现

历史项处理原因
B-01A / B-01C移出主标准只作为高度对照；B-01B 已确认。
OV-03 / OV-04删除已分别被 SH 系 Sheet 与 DG 系 Dialog 正式规则取代。
F-05删除被 LS-04“加载更多”取代。
F-13 / F-14删除被 SK-01/02/03 Sticky 规则取代。
F-16删除被 DG-02/03 破坏性确认规则取代。
F-12删除被 RS-01~05 响应式体系取代。
F-09 / F-10从 K-02 场景移除K-02 已由 KR-04/05 明确标题、次信息、标签的溢出规则。普通正文仍可单独使用文本截断。
ST-07 Skeleton不纳入核心当前本地数据优先，真正需要加载时用 LS 状态即可；若以后出现明显骨架屏需求再单独建标准。
F-08 浮动主操作按钮不纳入当前标准当前业务没有明确需要，容易与底部 Sticky 主操作冲突。
F-11 只读数据表不纳入移动端核心常规参数默认采用 MT-02/03；复杂表格以后按具体模块和横屏需求再设计。
MT-01保留为正式组件用于 2–3 个少量数据项；MT-02/03 用于指标更多的场景。
CP-01/02取消独立组件并入全局多色语义标签体系；AW 仅保留业务配色映射。
WA-01提升为全局组件定义多级列表 / 嵌套选项结构；AW 只保留弹种等游戏内配色。
SnowRunner 用户 A/B 色提升为全局成员身份色第一版至少 5 色；后续允许用户调整身份配色。
SnowRunner 完成态拆分“完成 / 成功”绿色语义提升为全局；COMPLETE 印章只是 SnowRunner 的表现变体。
F-06 Pagination保留为条件组件虽然当前不是主要模式，但对未来管理类列表可能有用，且已经确认对齐规则。

9. 实现与复核重点

Work 实现及后续 UI 复核时重点检查这些项目

  • B-01B 是否正式作为所有普通按钮默认视觉高度。
  • K-02 + KR 是否正式作为跨游戏“多标识内容卡”核心组件。
  • MT-01 / MT-02 / MT-03 是否按“2–3 项 / 常规单列 / 多项两列”正式进入全局标准。
  • WA-01 是否正式作为跨游戏多级列表 / 嵌套选项核心结构。
  • 多色标签 是否正式吸收 CP-01/02，并作为全局标签体系。
  • 成员身份色 是否正式采用至少 5 色的全局色板，并预留后续修改配色功能。
  • 完成态 是否正式作为全局状态语义，游戏只定义各自表现变体。
  • IC-01~04 是否正式采用统一图标资源规则，编辑固定使用笔图标。
  • SH / DG / SK / RS 是否可以直接进入全局标准。
  • SC-01 是否确认只归 AW 游戏内配色映射，不提升成全局颜色规则。
