# 全局 UI 整改 · 2026.10.04.7

## 范围与基准

本轮由用户集中反馈后统一开工，覆盖公共入口、SnowRunner、AW 及编辑弹层。以现有 SnowRunner 推进清单为视觉基准，不采用此前另拟的白底 / 16rpx 圆角卡片方案。基线为 PR #8 的 `4177de4`，本版代码号 `2026.10.04.7`，供人工上传时使用的版本号 `0.1.0-test.20261004.7`。

没有上传微信体验版、没有合并 main、没有访问或修改真实存档、数据库或公共资料发布服务。

## 具体整改

1. 前置 / Token 弹层顶部目标车、按钮型车辆卡、无视前置、自定义选择、加载更多及保存均明确容器宽度。满宽按钮使用行内宽度约束；全局按钮类提高选择器优先级，避免默认按钮固定宽度和自动外边距影响。
2. 每台 AW 车辆保持独立卡片；长车名只在名称列换行。组件不再生成车型图形字段或图形 CSS。
3. 筛选选项及角色选择从 text 标签改为显式的点击外层与居中底块，移除旧 88rpx 高度叠加大 padding 的规则。经销商等长选项按文字自适应宽度。
4. 普通、紧凑、危险、分段选择按钮全部使用共享类。独立主按钮占满所在栏，并排按钮共享父容器；取消、编辑、移除、感叹号仍为独立紧凑操作。
5. SnowRunner 卡片、按钮和页签接入同一来源；原勾选框、归属选项和排序图形保留可见样式，以独立点击槽扩大触摸范围。排序行允许必要换行，归属行与新的点击槽对齐。
6. 编辑弹层继续用弹性滚动区域保留底部操作；前置面板目标车不挤占标题 / 取消栏。
7. 上轮已隐藏的资料核验备注与内部配置编号继续保留后台数据，不恢复用户界面展示。
