# 微信合作游戏小程序 / wx_coopgames

用于管理合作游戏资料、团队计划与共享进度的微信小程序项目。

当前项目首先覆盖 **SnowRunner**，并正在加入 **Armored Warfare（AW）车辆资料库与团队车辆计划**。后续可继续扩展其他需要多人共享进度、车辆/装备计划或资料查询的游戏。

## 当前基准

小程序端当前以以下版本作为代码基准：

- **提交审核版：`coopgame-review-v3-collapse-full.zip`**
- 日期：2026-10-01
- 后续小程序修改均应从该版本进入 Git，不再以聊天附件或临时 ZIP 作为正式版本来源。

数据库当前使用 Supabase 项目：

- 项目名：`wx_coopgame`
- Git 仓库：`zeroga/wx_coopgames`

> Git 是项目代码、数据库结构变更和可维护数据文件的版本基准。  
> Supabase 是实际运行数据库，不应再通过大量不可追溯的临时 SQL 作为长期维护方式。

## 功能范围

### SnowRunner

现有小程序主要提供：

- PC / 主机双页签
- 双成员团队资料
- 团队码共享合作档
- 赛季与区域推进清单
- 目标勾选、编辑、增删
- 车辆取得与成员分配
- 顺序调整
- S1–S19 赛季数据
- 本体区域独立记录
- 云端共享状态

团队数据模型同时作为 AW 团队车辆计划的基础。

### Armored Warfare

AW 模块目标包括：

- 浏览车辆资料
- 按等级、车型、经销商、国家等基础条件筛选
- 按 ERA、烟幕、步兵班等车辆能力筛选
- 按自导导弹、攻顶导弹等弹药能力筛选
- 按 AP 穿深筛选
- 查看车辆主要武器与弹药
- 查看可研发配件
- 查看完整科技树
- 查看车辆研发 / Token 解锁条件
- 使用现有团队码共享车辆计划
- 查看其他成员已经计划的车辆
- 后续扩展为车队组建器

AW 第一版不使用车辆图片作为核心数据依赖，也暂不加入主观评分。

## 数据与版本管理原则

### 小程序代码

小程序源码直接进入本仓库。

正式基准由 Git commit 确定，不再依赖“最新版 ZIP”作为长期版本判断方式。

### Supabase Schema

数据库结构变更应进入：

```
supabase/migrations/
```

长期规则：

1. 先形成可审查的 migration。
2. 再应用到 Supabase。
3. 应用后验证实际数据库状态。
4. Git 与线上 migration history 保持对应。

临时诊断 SQL 可以直接执行，但永久结构修改不能只存在于一次聊天任务中。

### AW 数据

AW 车辆、武器、弹药、科技树与解锁资料需要长期维护。

原则上：

- 原始 / 可维护数据应进入 Git。
- Supabase 作为运行时查询数据库。
- 单车修正应能通过 Git diff 追溯。
- “未采集到”不能被解释成“游戏中不存在”。
- 无法公开确认的数据保持未知或待游戏内核实，不猜测补全。

截至 2026-10-01，AW 初始数据已经写入 Supabase，包括：

- 车辆

- 弹药

- 解锁路线与条件
- Tier 9 / Tier 10 Token 关系
- AW 团队车辆计划结构与 RPC

AW 当前结构和交付资料已经固化到仓库，入口见 [AW 数据库说明](docs/aw/README.md)：

- [幂等建表 SQL](supabase/sql/003_aw_catalog_idempotent.sql)：针对当前最终结构，正确存在的对象可重复执行。
- [只读验证 SQL](supabase/sql/004_aw_catalog_verify.sql)：连接、锁、migration、批次、质量与数量检查。
- [已执行 migration](supabase/migrations/)：与线上 14 个版本对应的历史记录。
- [公开数据快照](data/aw/catalog_snapshot.json)、[完整报告](docs/aw/AW_database_report.md)及[原交付包](docs/aw/AW_database_handoff.zip)。

当前共有 298 辆车辆、440 个武器配置、782 个弹药配置、1172 个升级项目。完整科技树的数据尚未核实齐全，缺口见报告。
已有数据库不要重新初始化；幂等建表与历史 migration 是不同入口，执行前先检查真实状态。

## 安全要求

本仓库为公开仓库。

禁止提交：

- Supabase `service_role` / secret key
- 私有数据库密码
- 微信平台私钥
- 用户真实团队码
- 其他访问令牌或账号密钥

前端只能使用适合公开客户端使用的配置，并依赖数据库端 RLS / RPC 做实际访问控制。
